# 🎨 Framer Motion Presentation Playground

A creative, experimental presentation playground built with **React**, **Tailwind CSS**, and **Framer Motion** designed for tech conferences and developer meetups (inspired by Google I/O and Apple WWDC keynote visuals).

---

## 🚀 Running the Presentation

```bash
cd ~/dev/presentation/how-we-use-ai-in-informatiq
npm run dev
```

Open `http://localhost:5173` and press **`F`** to go fullscreen.

---

## 🎪 What's in the Playground

| Slide | Concept | Framer Motion Showcase |
| :--- | :--- | :--- |
| **01** | **The Living Orb** | Google I/O morphing SVG organic geometry + kinetic typography + orbital spring pills |
| **02** | **The Synaptic Bridge** | Animated SVG path drawing (`drawSvg`) connecting human architectural taste with AI horsepower |
| **03** | **Kinetic Chaos to Flow** | Real spring physics (`stiffness: 400`, `damping: 18`) with draggable items and a central magnetic orb that resolves Friday night toil |
| **04** | **Temperature Dial** | Interactive slider controlling model creativity with a reactive, morphing SVG facial expression (robot ➔ smart ➔ chaos) |
| **05** | **Agent Swarm Network** | Autonomous multi-agent SVG light wave data bus with real-time active pulse heartbeats |
| **06** | **Kinetic Typography Finale** | Giant kinetic text layout with an interactive celebratory rocket particle burst |

## ⌨️ Controls & Navigation

- **Next / Prev:** `→` / `←` / `Space`
- **Fullscreen:** `F`
- **Presenter View:** `P` (For presenter view with notes and context)
- **Slide Navigator Drawer:** `O` or `Esc`
- **Dock:** Move mouse to bottom edge to reveal the floating macOS glass dock.
