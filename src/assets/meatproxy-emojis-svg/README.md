# Meat Proxy emoji pack

44 custom emojis of the meatproxy.me pink blob, for Slack, Discord, or anywhere
that takes a PNG. Free to use. Transparent backgrounds. https://meatproxy.me/slack-emojis

## Folders

- `*.png`      128x128, Slack-ready. Slack keeps the file name as the shortcode.
- `big/*.png`  512x512 for stickers, decks, Notion.
- `svg/*.svg`  traced vectors, recolor or scale as you like.

## Install

Slack: workspace menu > Customize workspace > Emoji > Add custom emoji, upload the 128px PNGs.
Discord: Server settings > Emoji > Upload emoji.
