# Project Rules (AI-Assisted Development Presentation Slides)

These are the rules and guidelines for the AI-Assisted Development presentation slides. They outline the approach, expectations, and constraints for creating and delivering the presentation.

1. There should be a file that lists all the slides with enabled/active status, so it is easy to enable or disable slides before the presentation. The slide number or order should reflect the intended sequence of the presentation. for instance, let's say we have 5 slides but right before the presentation we decide to disable slide 3, then when i ran the project, slide 3 should be skipped and the remaining slides should maintain their intended order.
