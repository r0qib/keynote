# Animation & Motion Guidelines

- Aim for premium, cinematic animations inspired by Apple WWDC, Google I/O, and Microsoft Build keynotes.
- Make animations feel smooth, elegant, intentional, and professionally choreographed.
- Treat motion as part of storytelling, not decoration.
- Use Framer Motion for transitions and element animations.

### Transitions

- Use seamless, smooth transitions between slides.
- Prefer morphing, shared-element, scale, and directional transitions over basic fade-only transitions.
- Where appropriate, make elements from one slide transform into elements on the next.
- Keep transitions consistent but not repetitive.

### Element Animations

- Use staggered reveals for text, diagrams, and visual elements.
- Use subtle word-by-word or line-by-line text reveals when appropriate.
- Prefer smooth movement, opacity, and scaling.
- Use carefully tuned easing and spring animations. Avoid mechanical or overly bouncy motion.
- Introduce complex diagrams progressively rather than displaying everything at once.

### Creative Techniques

- Use animated SVG paths, connecting lines, and arrows for workflows.
- Use masking, clipping, and layered transitions where they add visual impact.
- Use kinetic typography for important statements.
- Use coordinated animations to demonstrate relationships and transformations.
- Use dramatic zooms or transitions selectively for major moments.

### Avoid

- Generic fade-in animations on every element.
- Random bouncing, spinning, and excessive zooming.
- Cartoon-like or PowerPoint-style animations.
- Excessive blur, glow, particles, and decorative motion.
- Repeating the same animation pattern across every slide.
- Animations that distract from the actual content.

### Overall Direction

- Every slide should have its own intentional animation composition.
- Prioritize quality over quantity.
- Use subtle motion for explanations and more dramatic motion for important reveals.
- Make the entire presentation feel like a polished technology conference keynote, not an animated website.
- Do not animate just because you can. Every animation must serve a visual or storytelling purpose.
