# Animation Guide for AI-Assisted Development Presentation Slides

1. Each animation should be very smooth, avoiding abrupt transitions or jarring movements.
2. Use apple's magic move or similar smooth transition effects to create a seamless animation experience.
3. sometimes the animation will start big and then it will morph into a smaller size or different shape, creating a dynamic visual effect.
4. Some animations will stay on the screen until the user interacts with them. this will allow the presenter to control the pacing and allow him to reveal content exactly when needed.
5. Consider using subtle easing effects to make animations feel more natural and less mechanical.
6. Pay attention to the timing and duration of animations to ensure they are neither too fast nor too slow, maintaining audience engagement without causing distraction.
